关于

写代码的人，顺手做点小工具。

  • 工具：自己写、自己用的四个小东西
  • 文章：建站、上线、折腾的记录

这个站怎么搭的

没有 CMS、没有数据库、没有月费。内容是一份配置加几个 Markdown 文件，构建脚本把它们压成静态页，托管在免费额度里。

代价也明确：没有后台、没有评论、没有搜索。需要什么就自己加。

技术栈

纯 HTML / CSS / JavaScript
+ 一个 Node 构建脚本（预渲染 + sitemap + RSS）
+ Netlify 托管
